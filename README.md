Features:
- Works completely offline, without internet access
- Supports multiple languages (English, Chinese, Spanish, French, German, Italian, Russian)
- Import and export to Excel

This program was created for educational institutions that need a local, free, and—most importantly—accessible program

Release:

How to launch?

1. Windows

1) Download the ZIP archive
2) Extract it to an empty folder
3) Run Schedule.exe

2. Linux (Ubuntu)

Requirements:
glibc 2.38 (Ubuntu 24.04) or newer

1) Download the ZIP archive
2) Unzip Schedule-Linux_beta_1_0_0.zip -d Schedule
3) cd Schedule
4) ./Schedule

3. macOS

1) Download the ZIP archive
2) Extract it to an empty folder
3) Right-click and select “Open” (since Gatekeeper will block the unsigned application if you try to run it normally)
